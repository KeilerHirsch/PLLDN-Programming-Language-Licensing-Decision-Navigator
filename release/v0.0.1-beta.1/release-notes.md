# PLLDN v0.0.1 Beta 1

PLLDN's first public Beta publishes the verified deterministic decision core, static GitHub Pages runtime, and read-only community candidate tooling as one evidence-bound prerelease.

## Included

- Live decision surface for Go, Python, Rust, and TypeScript.
- Four reviewed boolean capability dimensions: runtime garbage collection, safe-code memory safety without GC, static type checker, and emits JavaScript.
- Deterministic free-text assistance that only proposes canonical facet changes and requires explicit confirmation.
- Reviewed knowledge snapshot, traceable decision evidence, and fail-closed trust boundaries.
- Static GitHub Pages deployment and read-only freshness/community advisory workflows.

## Important limits

Beta 1 does not yet expose a complete live licensing recommendation workflow. Eight SPDX license identities are Reviewed knowledge, but they are not part of the current Pages decision projection.

PLLDN does not provide legal advice, certification, universal natural-language understanding, broad recommendation-accuracy guarantees, repository import, or Stage 5C private-repository read integration. Correct abstention is expected when Reviewed evidence is insufficient.

See `reviewed-coverage.json`, `known-limitations.md`, `release-evidence.json`, and `SHA256SUMS` in this release for the exact machine-readable boundary and provenance.
