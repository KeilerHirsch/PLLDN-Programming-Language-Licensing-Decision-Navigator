# 0001 — Stage 0 repository foundation

Status: accepted for implementation, 2026-09-05.

Use TypeScript and explicit JSON Schema contracts. The planned static/local product
benefits from a shared language for validation, tests and later browser logic.
Node-specific schema loading is isolated and is not yet a browser adapter.

Use Node's test runner and Biome. Keep exact package pins and a committed lockfile.
Use jsonc-parser in strict mode to detect duplicate keys before parsing into objects.
This small dependency avoids maintaining a separate JSON grammar.

Use the existing external assurance evaluator through evidence reports.
Do not copy its private implementation into this public repository.
Classification, policy, evidence, enforcement and audit remain separate concerns.

Use EUPL-1.2 for own code, documentation and synthetic data.
The license text is copied without modification from SPDX license-list-data,
commit d46e94e2c78ceede1cfc63cfa0396472d2798d4c, text/EUPL-1.2.txt.
The same text is in LICENSE and LICENSES/EUPL-1.2.txt for conventional and REUSE tooling.

No framework, database, cloud provider, frontend, recommendation engine,
free-text parser or GitHub App authentication is selected or implemented here.
